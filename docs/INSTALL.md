# คู่มือติดตั้งระบบเวชระเบียน วพอ. บน Cloudflare

ทำตามลำดับนี้ทีละขั้น ทุกขั้นมีคำสั่งและสิ่งที่ต้องเห็นเมื่อสำเร็จ

## ภาพรวมระบบ

| ส่วน | ที่ใช้งาน | หมายเหตุ |
|---|---|---|
| หน้าเว็บทุกเมนู | Cloudflare Workers (Static Assets) | เปิดผ่าน Workers เสมอ |
| ตรวจสิทธิ์และรับคำสั่ง | Cloudflare Worker `/api/rpc` | ลงนามเหมือน HMAC ทุกคำขอ |
| ฐานข้อมูล | Google Sheets เดิม | เปิดด้วย ID เดิม ไม่สร้างใหม่ |
| ประวัติการใช้งาน | Google Apps Script (สคริปต์สะพาน) | รับเฉพาะคำขอที่ลงนามถูกต้อง |
| เอกสาร/ไฟล์ | Google Drive เดิม | ผ่านสิทธิ์ของบัญชีเจ้าของสคริปต์ |

ข้อมูลเดิมทั้งหมดยังอยู่ครบ โค้ดใหม่อ่านและเขียนชีตชุดเดิม ไม่ได้สร้างฐานข้อมูลใหม่

## ขั้นที่ 1: เตรียมโค้ดบนเครื่อง

```bash
npm install
npm run build
npm test
```

ต้องเห็น `pass 7 / fail 0` และข้อความ `Built Cloudflare website and isolated Google bridge in dist/`

ไฟล์ที่ได้
- `dist/public/` = เว็บไซต์สำหรับ Cloudflare
- `dist/google/Backend.gs` = สคริปต์สะพานสำหรับ Google (ตัวเดียว ไม่ต้องมีไฟล์อื่น)

## ขั้นที่ 2: ตั้งค่าบัญชีผู้ใช้ใน Sheets เดิม

เปิด Google Sheets ฐานข้อมูลเดิม > แท็บ `Users` แล้วตรวจว่ามีบัญชีผู้ดูแลระบบอยู่แล้ว

รหัสผ่านในระบบใหม่ต้องยาวอย่างน้อย 7 ตัวอักษร (รหัสประจำตัวของนักเรียนมี 7 หลัก) และ `PasswordHash` ต้องเก็บค่าแฮช SHA-256 ของคำนวณนี้

บัญชีผู้ดูแลควรใช้รหัสที่ยาวกว่านั้น เพราะ 7 ตัวอักษรเป็นค่าต่ำสุดที่ระบบยอมรับ ไม่ใช่ค่าที่แนะนำ

```
SHA-256( รหัสผ่าน + "AGY_MEDREC_SALT_2026" ) แล้วแปลงเป็นเลขฐาน 16 ตัวพิมพ์เล็ก
```

วิธีคำนวณโดยไม่ต้องใช้เครื่องมือเพิ่ม ให้รันคำสั่งนี้ในเครื่อง (แทนค่า `รหัสผ่านใหม่`)

```bash
node -e "const c=require('crypto');console.log(c.createHash('sha256').update('รหัสผ่านใหม่'+'AGY_MEDREC_SALT_2026','utf8').digest('hex'))"
```

นำค่าที่ได้ไปวางในช่อง `PasswordHash` ของแถวผู้ใช้นั้น
ห้ามส่งรหัสผ่านจริงมาในแชทนี้

ตรวจว่าสำเร็จ: ช่อง `Role` เป็น `ADMIN` หรือ `MEDICAL` และ `IsActive` เป็น `TRUE`

## ขั้นที่ 3: เปิดสคริปต์สะพานบน Google

โปรเจกต์สะพานถูกสร้างและอัปโหลดโค้ดไว้แล้ว ชื่อ **RTAFNC Health Bridge**

1. เปิด https://script.google.com/d/1UzGzmnSmk9Ss5Oyvhhn0-mmXwpNk2EZf-QKx2_f0qAf1VcFclsUQqyTr/edit
2. ไฟล์ `Backend.gs` มีโค้ดจาก `dist/google/Backend.gs` อยู่ครบแล้ว ไม่ต้องวางเอง
3. ไปที่ Project Settings > แถบ **Manifest** ตรวจว่ามีบล็อกนี้

```json
"webapp": { "access": "ANYONE_ANONYMOUS", "executeAs": "USER_DEPLOYING" }
```

โปรเจกต์นี้แยกจากโปรเจกต์เดิมของระบบ Apps Script โค้ดเดิมยังไม่ถูกแตะ

ตรวจว่าสำเร็จ: เปิดไฟล์ `Backend.gs` แล้วเห็นข้อความ `Generated by npm run build` และมีฟังก์ชัน `doPost`

## ขั้นที่ 4: ใส่ค่าความลับตอน build

ค่าความลับฝังเข้าไปในโค้ดที่ build ออกมา ไม่ต้องคลิกใน Script Properties

```bash
export GAS_BRIDGE_SECRET="$(openssl rand -hex 32)"   # เก็บค่านี้ไว้ ใช้ซ้ำในขั้นที่ 5
export SPREADSHEET_ID='<ID ของ Google Sheets ฐานข้อมูลเดิม>'
npm run build
```

`dist/google/Backend.gs` จะมีบรรทัด `const CF_CONFIG_ = {...}` ที่บรรจ��ค่าไว้ ให้ดันไฟล์นี้ขึ้นสคริปต์สะพานในขั้นที่ 3

ผู้ที่เปิดดูโค้ดสคริปต์ได้คือเจ้าของและผู้แก้ไขโปรเจกต์เท่านั้น ผู้ใช้ทั่วไปที่เรียก URL สะพานโดยตรงอ่านโค้ดไม่ได้ อย่างไรก็ตาม `dist/` อยู่ใน `.gitignore` แล้ว จึงไม่มีค่าความลับหลุดเข้า Git

ทางเลือกที่ปลอดภัยกว่า: ใส่ค่าใน Script Properties ของสคริปต์สะพานแทน โดยตั้งชื่อคีย์ `GAS_BRIDGE_SECRET` และ `SPREADSHEET_ID` ค่าใน Script Properties จะถูกใช้แทนค่าที่ฝังไว้เสมอ การสลับวิธีนี้ได้โดยไม่ต้องแก้โค้ด

ค่า `CF_NOTIFICATIONS_ENABLED` มีค่าเริ่มต้นเป็น `FALSE` อยู่แล้วในโค้ด ไม่ต้องทำอะไร Telegram จะยังไม่ส่ง ถ้าต้องการเปิดใช้งานให้เพิ่ม `TELEGRAM_BOT_TOKEN` และ `TELEGRAM_CHAT_ID` ใน Script Properties แล้วเปลี่ยน `CF_NOTIFICATIONS_ENABLED` เป็น `TRUE`

## ขั้นที่ 5: ใส่ Secret ฝั่ง Cloudflare และ deploy เว็บ

```bash
npx wrangler login
npx wrangler secret put GAS_BRIDGE_SECRET      # ค่าเดียวกับขั้นที่ 4
npm run deploy:check                          # ต้องผ่านก่อน deploy จริง
npm run deploy
```

`GAS_WEB_APP_URL` ยังใส่ไม่ได้ในขั้นนี้ เพราะยังไม่มี URL ของสคริปต์ ให้ข้ามไปก่อนแล้วกลับมาใส่ในขั้นที่ 7

ตรวจว่าสำเร็จ: ได้ URL โดเมนของ Worker จากผลคำสั่งจริง และเปิด URL นั้นแล้วเห็นหน้าเข้าสู่ระบบ

## ขั้นที่ 6: Deploy สคริปต์สะพานเป็น Web app

ต้องทำหลังขั้นที่ 5 เพราะ Worker ต้องรู้ URL ของสคริปต์

1. ที่โปรเจกต์สะพาน กด **Deploy > New deployment > Web app**
2. Execute as: **Me** และ Who has access: **Anyone**
3. คัดลอก URL ที่ได้ รูปแบบคือ `https://script.google.com/macros/s/AKfy.../exec`

ตรวจว่าสำเร็จ: เปิด URL นั้นในเบราว์เซอร์แล้วได้ข้อความ JSON สั้น ๆ ว่า `ok: true` ไม่ใช่หน้าเข้าสู่ระบบ Google

## ขั้นที่ 7: เชื่อม Worker เข้ากับสคริปต์

```bash
printf '%s' 'https://script.google.com/macros/s/<DEPLOYMENT_ID>/exec' | npx wrangler secret put GAS_WEB_APP_URL
```

ตรวจว่าสำเร็จ: เปิดหน้าเว็บแล้วล็อกอินได้ ถ้ายังขึ้น `เชื่อมต่อ Google ไม่สำเร็จ` แสดงว่าค่ายังไม่ถูกต้อง ดู `docs/TROUBLESHOOTING.md`

## ขั้นที่ 8: ทดสอบการเข้าสู่ระบบ

1. เปิด URL ของ Worker ในเบราว์เซอร์
2. ล็อกอินด้วยบัญชีที่ตั้งไว้ในขั้นที่ 2
3. เมนูด้านซ้ายต้องแสดงครบตามสิทธิ์ของบัญชีนั้น

ถ้าขึ้น `เชื่อมต่อ Google ไม่สำเร็จ` แสดงว่า Worker ยังตั้งค่าไม่ครบ ให้ตรวจ `GAS_WEB_APP_URL` และ `GAS_BRIDGE_SECRET` ว่าตรงกันทั้งสองฝั่ง

## ขั้นที่ 9: เชื่อม LINE LIFF (ทำเมื่อพร้อม)

1. ใน LINE Developers Console เปิดสิทธิ์ `openid` และ `profile` ของ LIFF
2. ตั้ง Endpoint URL เป็นโดเมน Cloudflare + `?page=liff`
3. เพิ่มค่าใน Script Properties ของสคริปต์สะพาน

| คีย์ | ค่า |
|---|---|
| `LINE_LIFF_ID` | LIFF ID จาก Console |
| `LINE_LOGIN_CHANNEL_ID` | Channel ID จาก Console |
| `LINE_STUDENT_<USER_ID>` | ผูกบัญชี LINE กับรหัสนักเรียน 7 หลัก |

ระบบจะไม่ยอมให้เปิดดูประวัติของนักเรียนอื่น เพราะตรวจ ID token กับ LINE แล้วเทียบกับค่าที่ผู้ดูแลผูกไว้เท่านั้น

## การสำรองและย้อนกลับ

สำรองฐานข้อมูล: ใน Google Sheets ใช้ File > Make a copy เก็บไว้เป็นรายเดือน

ย้อนเว็บ Cloudflare: `npx wrangler rollback` เลือกเวอร์ชันก่อนหน้า หน้าเว็บย้อนได้ทันที

ย้อนสคริปต์: ใน Apps Script เลือก deployment เก่า แล้ว Deploy > Manage deployments > Edit > Version: New version

ข้อควรรู้: การย้อนโค้ดไม่ได้ย้อนข้อมูลในฐานข้อมูล ถ้ามีการเขียนข้อมูลจริงแล้วต้องกู้จากไฟล์สำรองแยกต่างหาก

## การยกเลิกการเชื่อมต่อ

1. ลบ `GAS_BRIDGE_SECRET` และ `GAS_WEB_APP_URL` ที่ Cloudflare (`npx wrangler secret delete <KEY>`)
2. ปิดการใช้งาน deployment ของสคริปต์
3. ลบโปรเจกต์สะพานเมื่อไม่ใช้แล้ว
